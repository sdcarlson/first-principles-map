# first-principles-map

Typed graph of axioms, models, and named gaps. Fields are not nodes. A leftover attaches to the model that leaks.

The map is drawn from `graph.json`. Add a node there. Do not mint an axiom to close a hole.

`think.html` is a workout for one problem. It does not write the map.
