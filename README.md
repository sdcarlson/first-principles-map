# What still has to be true

Gold boxes still hold if a blue story is wrong. Blue boxes are today's explanations. Red boxes are what those explanations still cannot explain. A name is not a new starting rule.

The map is drawn from `graph.json`. Add a leftover there. Don't invent a starting rule to close a hole.

`think.html` is for one problem. It does not write the map.
